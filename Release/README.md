# MAKMOUSE CAD Software

*English version below.*

Sterownik myszy 3D MAKMOUSE dla programów CAD (Fusion 360, Inventor). Zamienia
gałkę, pierścień i przyciski boczne (trzy albo sześć — do wyboru w *Ustawieniach*)
w pełną nawigację 3D, jak w profesjonalnych manipulatorach 3D.

## Pobieranie

Najnowsza wersja: **[Releases → Latest](https://github.com/makao1253/MAKMOUSE-CAD-Software/releases/latest)**,
sekcja **Assets**. Wybierz jeden z dwóch plików:

| Plik | Kiedy |
|---|---|
| `MAKMOUSE-<wersja>-setup.exe` | **zalecany** — instalator: skrót w menu Start, opcjonalnie skrót na pulpicie, autostart i dodatek do Fusion 360; odinstalowanie przez *Aplikacje i funkcje* |
| `MAKMOUSE-<wersja>-portable.exe` | jeden plik bez instalacji — uruchamiasz od razu, np. z pendrive'a; start trwa kilka sekund |

**Wymagania:** Windows 10 lub 11, 64-bit. Python nie jest potrzebny.

### „System Windows ochronił ten komputer”

Pliki nie są podpisane certyfikatem, więc przy pierwszym uruchomieniu Windows
może pokazać to ostrzeżenie. Kliknij **Więcej informacji → Uruchom mimo to**.

### Dodatek do Fusion 360

Zaznacz w instalatorze *Zainstaluj dodatek do Fusion 360*, a potem w Fusionie:
*Utilities → Scripts and Add-Ins* (`Shift`+`S`) → zakładka **Add-Ins** →
`MAKMOUSE` → **Run** i zaznacz **Run on Startup**.

### Aktualizacja

Pobierz nowy instalator i uruchom go — zastąpi poprzednią wersję. Twoja
konfiguracja zostaje.

## English

Driver for the MAKMOUSE 3D mouse for CAD applications (Fusion 360, Inventor).
It turns the knob, the ring and the side buttons (three or six — chosen in
*Settings*) into full 3D navigation, as with professional 3D mice.

### Download

Latest version: **[Releases → Latest](https://github.com/makao1253/MAKMOUSE-CAD-Software/releases/latest)**,
**Assets** section. Pick one of the two files:

| File | When |
|---|---|
| `MAKMOUSE-<version>-setup.exe` | **recommended** — installer: Start menu shortcut, optional desktop shortcut, start with Windows and the Fusion 360 add-in; uninstall through *Apps & features* |
| `MAKMOUSE-<version>-portable.exe` | a single file, no installation — run it straight away, e.g. from a USB stick; starts in a few seconds |

**Requirements:** Windows 10 or 11, 64-bit. Python is not needed.

### "Windows protected your PC"

The files are not code-signed, so Windows may show this warning on the first
run. Click **More info → Run anyway**.

### Fusion 360 add-in

Tick *Install the Fusion 360 add-in* in the installer, then in Fusion:
*Utilities → Scripts and Add-Ins* (`Shift`+`S`) → **Add-Ins** tab →
`MAKMOUSE` → **Run**, and tick **Run on Startup**.

### Updating

Download the new installer and run it — it replaces the previous version.
Your configuration is kept.
